# 今晚先睡 · 微信小程序工程 v0.1

## 导入运行
1. 打开「微信开发者工具」（稳定版即可）
2. 导入项目 → 选择本目录 → AppID 已写在 project.config.json 里（wx6d0eedae0b4a34db）
3. 编译即可在模拟器预览；真机预览点「预览」扫码

## 本版已实现（核心仪式链路）
- 夜空首页：背景星空、真实月相、星星诞生动画、星星详情浮层、翻篇金色仪式、删除
- 星回：30 天未翻篇的星带金晕 + 首页横幅，回看作答（翻篇 / 再放一会儿 / 续写）
- 书写页：输入校验、「借一句话开头」引导、情绪标签
- 回应页：原文引用 + 放它走释放动画（文字化光点飞升）
- 呼吸页：每日引导词 + 呼吸光球
- 数据：wx.setStorageSync 本地存储（二期云同步只改 utils/store.js）

## 调试入口
星回默认 30 天触发。在开发者工具「编译模式 → 启动页面」填
`pages/sky/sky?revisit=0` 可让所有未翻篇的星立即进入回看状态。
