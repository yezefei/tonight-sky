# 今晚先睡 · 微信小程序工程

## 导入运行
1. 打开「微信开发者工具」（稳定版即可）
2. 导入项目 → 选择本目录 → AppID 已写在 `project.config.json` 里（`wx6d0eedae0b4a34db`）
3. 编译即可在模拟器预览；真机预览点「预览」扫码
4. 云开发环境 ID 写在 `utils/config.js`；未配置时本地功能照常可用

## 已实现
- **底部三 tab**：今夜（写与陪伴）/ 星空（看星、筛选、统计）/ 我的（概览、心情日历、隐私与数据）。自定义 tabBar 在 `custom-tab-bar/`，采用「悬浮胶囊」方案：居中窄胶囊浮在夜空上，图标与文字横排，选中项金色；三个 tab 页底部留白已同步加高，避免胶囊压住内容
- 夜空首页：**canvas 装饰星空**（`components/skyfield/`：银河柔光带 / 漂移星云 / 三层闪烁星点 / 6 颗呼吸式明暗星 / 三颗成组流星，30fps、切后台停帧；纯装饰，不读取用户记录）+ 三层恒星轨道、星星诞生动画、详情浮层、翻篇金色仪式、删除。**用户写下的星只在恒星轨道展示，不再混入首页背景**
- 星回：30 天未翻篇的星带金晕 + 首页横幅，回看作答（翻篇 / 再放一会儿 / 续写），显示「当时 vs 现在」
- 书写页：文字 / 语音输入（同声传译插件）、草稿自动保存、话题标签 + 三档情绪强度 + 情绪词
- 回应页：原文引用 + 交给夜空仪式动画
- 呼吸页：4-7-8 呼吸法（鼻吸 4s / 屏息 7s / 口呼 8s），薄荷色进度环 + 呼吸光球 + 大数字倒数；5 轮收尾，也可切「一直陪着我」不限轮手动停
- **入睡收尾**：交给夜空 / 晚安 / 五轮呼吸后渐暗到黑，轻触唤醒
- **定制安抚**：按今晚标签与关键词在本机匹配一句回应，不上传、不接 AI
- **睡不着陪伴页**：全屏深空 + 20 秒轮换安抚词 + 渐暗入口
- 星志列表（星空 tab）：4 类型页签 + 月份分组 + 标签筛选 + 触底加载 + 近 7 天/本月回顾；独立星星详情页
- **心情日历**（我的 tab）：按本机日期回看每天写过什么，点日期看当天记录并可进单星详情；月度统计记录天数 / 星数 / 心情词与话题频次。只回看，不打卡、不计连续天数、不评价情绪好坏
- **隐私与数据**（我的 tab）：隐私说明正文 + 云同步 / 立即同步 / 回音提醒 / 导出 / 清空，集中在一页
- 晚安卡：5 种 canvas 卡面滑选（3 免费：深夜蓝/鎏金/信纸；2 会员限定：圣诞节限定/平安夜限定）
- 送星全链路：shareCreate → 收星页 → 回复 → 流星通知 → 回执
- **云同步**：「我的 → 隐私与数据」可开启，支持导出 / 清空；默认关闭。情绪强度 / 情绪词 / 星回现状仅存本机，不上传
- **订阅消息**：模板 ID 配好后自动登记（见 `cloudfunctions/README.md`）

## 调试入口
星回默认 30 天触发。在开发者工具「编译模式 → 启动页面」填
`pages/sky/sky?revisit=0` 可让所有未翻篇的星立即进入回看状态。

## 云同步使用
1. 云开发控制台建 `stars` 集合，部署 `starsSync` 云函数
2. 给 `starsSync` 配 `CONTENT_KEY`（与其他加密函数同值）
3. 小程序「我的」tab → 隐私与数据 → 云同步 → 打开开关
