## 一、项目介绍

**今晚先睡**——微信小程序，一个夜间情绪出口。

核心设定：用户深夜把心里的事写下来，经「把它交给夜空」仪式后变成一颗星，围绕恒星在轨道上运行。

核心玩法：
- **写心事 → 变成星**：支持文字 + 语音输入，可选话题标签、三档情绪强度（淡淡 / 比较明显 / 很强烈）与情绪词（平静 / 开心 / 兴奋 / 安心 / 累 / 烦 / 委屈 / 失望 / 空），写完经「谢谢你，愿意说出来」仪式页释放成星。强度与情绪词均为中性表达，不预设写的是难过的事
- **恒星环绕**：所有星分三层轨道绕恒星旋转（深空观测台视觉），点星看原话
- **翻篇**：对一颗星说「这件事翻篇了」→ 镀金爆裂变成金色四角星（可 5 秒内撤销）
- **送星给好友**：1 对 1 分享，好友可回一句话（回音），回音到达时一颗流星划过屏幕坠下提示拆开
- **星回**：30 天前的星会回来「让你回头看看」，显示当时的强度/情绪，并可记下「现在怎么样了」形成对比
- **呼吸页**：4-7-8 呼吸法（鼻吸 4s / 屏息 7s / 口呼 8s），薄荷色进度环 + 浅色呼吸球 + 大数字倒数，屏息提示「别憋太用力」；5 轮后温柔收尾，也可切「一直陪着我」不限轮手动停
- **渐暗入睡**：点「晚安」或完成五轮呼吸后，屏幕在 3 秒内暗下去，浮出「把手机放下吧，我已经替你记着了」，轻触任意处唤醒
- **睡不着陪伴**：「就是睡不着」入口进入安静页，慢速星野 + 每 20 秒一句安抚词，并带出按今晚心事（标签 / 关键词，纯本地）匹配的回应
- **星志列表**：按类型（全部/心事/有回音/已翻篇）浏览日志，月份分组 + 标签筛选 + 触底加载；顶部展示近 7 天 / 本月记录数与「写过几天」，不计算平均强度（情绪不打分）
- **星星详情页**：修改内容、翻篇、送好友、回执、存卡片、删除
- **晚安卡**：5 种卡面风格可滑动选择（3 免费：深夜蓝/鎏金/信纸；2 会员限定：圣诞节限定/平安夜限定），存相册分享。会员限定卡沿用归档《开发交接文档》第 11 节视觉规范：深空底 + 暖白/金星 + 极简符号，不做具象节日插画

## 四、技术架构

**技术栈**：微信小程序原生（WXML/WXSS/JS，无框架）+ 云开发（云函数 + 云数据库）。

### 云函数（`cloudfunctions/`）

| 函数 | 作用 |
|---|---|
| `shareCreate` | 生成送星分享：msgSecCheck 内容安全 → AES-256-GCM 加密入库 → 返回 shareId |
| `shareOpen` | 打开分享：waiting→opened 原子流转（仅接收方）、回音已读标记（发送方）、返回 ack 状态 |
| `shareReply` | 接收方回复：过审 → 加密入库 → 状态转 replied |
| `replyCheck` | 发送方轮询：拉未读回音（replySeen≠true）+ 已打开未回的分享（opened 状态） |
| `shareAck` | 回音回执：发送方标记「我收到了」（ack=true，幂等） |
| `notifySubscribe` | 登记订阅消息授权（一次授权发一条，发完即删） |
| `starsSync` | 星星云同步：按 id 合并、updatedAt 新者胜、删除墓碑 30 天后清理 |

### 数据模型

**本地缓存**（默认只存本地；用户在「我的 → 隐私与数据」开启同步后才上传）：
- `tonight-sky-v1`：星星数组 `{id, t, tag, text, intensity, emotion, x, y, done, sent, shareId, reply, opened, ack, snoozed, more[], rvNow, received, updatedAt, deletedAt?}`；`intensity` / `emotion` / `rvNow` 仅本地，不上传
- `tonight-write-draft`：写心事草稿 `{text, tag, intensity, emotion, t}`
- `tonight-reply-announced`：已播报流星通知的 shareId 数组（去重）
- `tonight-vip`：会员开关占位
- `tonight-sync-enabled` / `tonight-sync-last`：同步开关与上次同步时间

**云数据库集合**：
- `shares`：分享载体 `{_id, from(openid), type, payload{text加密,tag}, status(waiting/opened/replied), openedAt, reply加密, replyEnc, repliedAt, replySeen, ack, ackAt, expireAt}`。权限：仅创建者可读写，客户端不直查，全走云函数
- `subscriptions`：订阅授权队列
- `stars`：云同步星星 `{_openid, id, updatedAt, deletedAt?, text(密文), tag, x, y, done, sent, shareId, reply(密文), opened, ack, snoozed, more[](密文), received}`。`intensity` / `emotion` / `rvNow` 属更敏感的本地字段，上传前剥离、合并后回填，不进云端。权限：仅创建者可读写，客户端不直查，全走 starsSync

### 常见坑速查
| 症状 | 原因 | 解法 |
|---|---|---|
| 云函数报 SYS | CONTENT_KEY 没配/不一致 | web 控制台检查 4 个函数环境变量 |
| `Cannot find module 'wx-server-sdk'` | 部署没带依赖 | 右键「上传并部署：云端安装依赖」 |
| 语音按钮不显示 | 同声传译插件没加/版本不对 | mp 后台插件管理添加；核对 app.json 版本号 |
| 真机录音没反应 | 隐私指引没声明麦克风 | mp 后台 → 服务内容声明 → 用户隐私保护指引 |
| 同一条回音不重复来流星 | 设计如此（replySeen + 本地已播名单） | 换新回复测；或清 `tonight-reply-announced` + 数据库把 replySeen 改 false |
| canvas 报「xxx is not a function」 | 旧版 canvas API 名字不同 | 径向渐变用 `createCircularGradient`（不是 createRadialGradient） |
| 云函数报 `CONTENT_KEY 未配置` | fail closed 生效，新函数没配密钥 | 给五个加密函数配同值 `CONTENT_KEY` 后重新部署 |
| 订阅消息没到 / 点击打不开对应版本 | 模板 ID 为空或 `MP_STATE` 不对 | 填模板 ID；体验版设 `trial`，线上设 `formal` |
| 开了云同步但两台设备不一致 | 新函数未部署 / `stars` 集合未建 / 密钥没配 | 按 `cloudfunctions/README.md` 逐项检查，设置页点「立即同步」 |

## 九、关键决策记录（为什么这么做）

1. **弹窗只在恒星页**：列表页点卡片进独立详情页（支持编辑等复杂操作），轨道页保快速浏览弹层——两类场景动线不同
2. **回音只通知一次**：`replySeen`（云端）+ `tonight-reply-announced`（本地）双去重，同一条回音不重复划流星
3. **流星只在 App 前台**：微信不允许小程序离线主动推送，离线触达只能靠订阅消息（待申请）
4. **分享内容全加密**：`shares` 集合里心事/回音都是 AES-256-GCM 密文，数据库管理员也看不到明文（但密钥在服务端环境变量，不是零知识，文案不要过度承诺）
5. **陌生人社交不做**（2026-11-25 结论）：社交类目需要非个人主体 + ICP 许可证，且微信对漂流瓶形态审核极严；替代方向：AI 宇宙回信（零 UGC 风险）> 熟人小星空 > 固定语安慰
6. **卡片会员模式**：免费 3 张 + 会员可预览不可存（种草逻辑），比「直接锁死看不见」转化好
7. **星星编号全局一致**：按写下时间排序编号（最早=01），轨道、列表、详情页通用，删除后自动重排
8. **云同步默认关闭**：隐私优先，用户主动开启才上传；删除用墓碑而非立即硬删，避免多设备间误删。同步失败不影响本地使用
